A Smart Fire Detection and Emergency Reporting Platform that combines IoT-based fire detection with a web application for reporting and monitoring emergency incidents.

Features
- Fire detection using ESP32 and MQ2 sensor
- Real-time emergency reporting
- Interactive incident map
- Firebase database integration
- Route guidance to incident locations
- Multiple emergency categories

- Technologies
    Hardware:
      - ESP32
      - MQ2 Smoke Sensor
      - Buzzer
      - LED

    Software:
      - HTML
      - CSS
      -  JavaScript
      - Firebase
      - Leaflet Maps
